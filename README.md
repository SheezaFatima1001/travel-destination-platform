\# Travel Destination Platform



A full-stack Travel \& Tourism Experience Platform built using the MERN Stack.



\## Technologies Used



\### Frontend

\- React.js

\- Vite

\- React Router

\- Axios

\- CSS



\### Backend

\- Node.js

\- Express.js

\- Mongoose

\- MongoDB

\- CORS

\- dotenv



\## Features



\- Responsive home page

\- Hero section

\- Travel categories

\- Featured destinations

\- Destination listing

\- Destination details

\- About page

\- Contact page

\- Admin dashboard

\- Add destinations

\- Update destinations

\- Delete destinations

\- Retrieve destinations from MongoDB

\- RESTful API

\- React and Express integration
